# Computer-Vision
# Computer Vision Practical 

## Project Overview
This project implements image processing, feature detection, object detection, and video motion analysis techniques using Python and OpenCV.

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-image
- Ultralytics YOLO
- Jupyter Notebook

## Project Structure
- `input/` – Original input images.
- `outputs/` – Generated output images from the experiments.
- `CCA3_Unit3.ipynb` – Complete implementation of the practical experiments.

## Experiments Implemented

### Unit 3 – Image Processing
- Gaussian and salt-and-pepper noise
- Median and Gaussian filtering
- PSNR and SSIM evaluation
- Thresholding and morphological operations
- Canny edge detection
- Watershed segmentation

### Unit 4 – Feature Detection
- Histogram of Oriented Gradients (HOG)
- SIFT keypoint and descriptor extraction
- Feature matching
- Rotation and resizing experiments

### Unit 5 – Object Detection and Motion Analysis
- Haar Cascade face detection
- YOLO object detection
- Video frame extraction
- Frame differencing
- GMM background subtraction
- Lucas–Kanade optical flow

## Execution
Open `CCA3_Unit3.ipynb` using Jupyter Notebook or Google Colab. Install the required Python libraries before executing the notebook.
